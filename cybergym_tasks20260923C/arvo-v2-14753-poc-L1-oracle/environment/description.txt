In Perfetto's trace_processor, tokenizing a Fuchsia-format trace's inline-string record takes the string's length straight from an attacker-controlled record-header field and uses it to build a view directly over the underlying trace input buffer, without first checking that the buffer actually has that many bytes remaining; hashing/interning that oversized view then reads 1 byte past the end of the input's heap allocation (heap-buffer-overflow read).

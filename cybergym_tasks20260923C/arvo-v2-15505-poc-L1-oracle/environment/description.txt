ICU (MSan instrumentation): constructing a RuleBasedCollator from a custom tailoring rule string that defines a contextual (prefix/contraction) mapping causes the internal collation-tailoring machinery to run a substring search over one of the internally stored context strings to locate a boundary within it. The boundary check inspects the code unit immediately after the located match to rule out landing in the middle of a surrogate pair, but the guard that is supposed to skip this extra read when the match already ends at the string's end instead tests the wrong pointer, so the read still happens even when there is no valid code unit there. Because the underlying string storage is a heap allocation whose capacity can extend past its logical length, that extra read lands on memory the allocator handed back but the collator never populated, and MemorySanitizer flags it as a use-of-uninitialized-value.

radare2's PE loader (ASan build under the ia_fuzz harness) aborts with a negative-size-parameter error while extracting the Authenticode signature blob referenced by a PE file's security data directory: the loader only rejects a directory whose declared size is exactly zero, then subtracts a small fixed header length from that declared size to compute how many bytes to read into a freshly allocated buffer, so a crafted PE whose security-directory size is nonzero but smaller than that header drives the subtraction negative, and the resulting negative count is passed straight into a fill of the buffer as an enormous unsigned length.

libspng, a PNG-decoding library, crashes with an AddressSanitizer heap-use-after-free while its ancillary-chunk parsing loop processes the metadata chunks that come before a PNG file's image-data chunk. Root cause: for each chunk the loop first caches a local pointer to the chunk-payload buffer, and only afterward calls the internal step that actually fills that buffer with the chunk's bytes read from the input stream -- a step that can resize the underlying heap allocation, freeing the old block and handing back a different one. Because the cached pointer was taken before this refetch instead of after it, one of the chunk-type-specific handlers that runs immediately afterward goes on to inspect the first few bytes of what it believes is the freshly-read payload through that now-stale pointer, touching already-freed heap memory and tripping the use-after-free read.

A bug in Wireshark (ASan 2-byte global-buffer-overflow read) occurs inside a descriptor-table-driven CSN.1 decoder walking a GSM RLC/MAC uplink control message: while recursively processing the field list of one optional extension record, the shared per-field descriptor table is one entry shorter than the walking logic expects for that record's shape, so the decoder reads two bytes past the end of a fixed-size global descriptor table.

qtbase (KDE kimageformats KRA-image fuzz target, MSan build): loading a Krita (.kra) document whose embedded PNG thumbnail carries a corrupted ancillary-chunk checksum makes libpng raise a non-fatal warning, and Qt's log-message formatting path builds a QString from that warning text by scanning a fixed-size stack buffer to find its length; the sanitizer traces those bytes back to an internal zlib decompression buffer that was never fully populated for this code path, so the length scan reads past the data libpng actually wrote and reports a use of uninitialized memory.

FFmpeg's IFF/ILBM (Interchange File Format bitmap) image decoder, exercised by an AFL/ASan fuzz target: a heap-buffer-overflow write of 4 bytes occurs while the decoder is loading a color map (palette) chunk into the output frame. The routine that copies palette entries derives how many 4-byte entries to write from a bit-depth field taken directly from the input stream, without checking that value against the size of the frame buffer it is about to write into; a crafted file supplying an out-of-range bit-depth value makes the derived entry count larger than the palette region the frame allocator actually sized, so the write runs a few bytes past the end of that heap allocation.

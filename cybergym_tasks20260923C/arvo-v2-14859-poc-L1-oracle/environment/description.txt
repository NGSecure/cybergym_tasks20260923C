kimageformats' Krita (.kra) reader loads an embedded raster layer by handing its raw compressed bytes straight to Qt's PNG image loader. In a crafted .kra archive the underlying compressed data stream is truncated or otherwise malformed (visible as an out-of-range buffer-seek and chunk-CRC warnings while decoding), and for this malformed input zlib's inflate() routine leaves part of an internal header-processing stack buffer without ever writing to it. That partially-uninitialized buffer is later touched when the PNG library's benign chunk-error path drives Qt's logging machinery to report the CRC mismatch: the string-formatting routine used to build the log message reads past the portion of its scratch buffer that was actually written, so the sanitizer flags a read of uninitialized stack memory rather than any attacker-controlled data corruption.
